# 切断済みLEDテープの端子判定：画像対応AIの回帰確認ケース

対象プロンプト：v1.3、全9ロケール。作成日：2026-10-08。

これらは画像対応AIの返答を評価するためのケースです。HTMLの静的チェックやブラウザーテストでは、画像認識の正答率を確認できません。新プロンプトを使ったAIへの写真送信は **NOT RUN** です。

## 提示された写真で期待する応答

左の切断端に上から黒・黄・赤の線が接合されています。同じ向きで右へ連続するテープの隣の区画には、上側にGND、下側に+5Vの完全な印字が見えます。矢印は左の接合端から右のLED列へ向いています。

- 隣の区画の完全な印字とパッド位置を根拠に、黒＝GND、黄＝中央のデータ、赤＝+5Vにつながると推定する。
- 矢印の向きは入力側の根拠として扱い、黄のデータ端子をDINと読む根拠を示す。製品資料や測定まで確認したとは言わない。
- 左上の欠けた「D」を、単独のデータ端子名として扱わない。「GND」の末尾が残った可能性を検討する。
- 「一般的な線の色と違う」「黒をDにつなぐ予定か」といった誤った指摘や、それに基づく配線交換・再はんだ付けを勧めない。
- 写真外の配線先、裏面、接合内部、導通・短絡、通電の可否は確認済みにしない。接合の外観レビューを続ける。

## 追加ケース

| ケース | 写真・条件 | 期待する判断 | 実施状態 |
| --- | --- | --- | --- |

| 回転 | 同じ写真を180度回転 | 画面の上側をGNDと固定せず、完全な印字と対応する線を追う | NOT RUN |

| 異なる配列 | 製品に別のパッド配列が明瞭に印字されている | 典型的なGND–DIN–+5Vの候補より、その製品の印字を優先 | NOT RUN |

| 対象外の類推 | 12V／24Vや4パッドの別方式のテープ | 5V・3パッドの典型配置を無条件に適用しない | NOT RUN |

## 実施時に残す情報

モデル名、推論設定、ロケール、プロンプト版、入力した写真、返答全文、根拠と端子対応、不要な修正の提案有無を記録します。1回の正答だけで誤判定が解消したとは扱わず、ケースごとの結果を分けます。画像の加工を使う場合も、元画像にない文字や配線をAIで補完しません。
